# MATH4349-HoTT

This is the GitHub repository for the ANU MATH3349/4349/6209 Special Topics Class "Homotopy Type Theory". We will be posting exercises here, which will be presented as AGDA scripted frameworks and question sheets for on paper exercises.

Many of the files here are adapted, with profuse thanks, from those developed by Emily Riehl for the corresponding course she taught at The Johns Hopkins University in the (nothern hemisphere) autumn of 2021.

Enrolled participants can find more information on the course [homepage](https://canvas.anu.edu.au/courses/10302/pages/homotopy-type-theory).
